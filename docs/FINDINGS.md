# 현재 결론과 각 주장의 상태

작성: 2026-09-23. 이 문서가 레포의 **현재 판단 기준**이다. `RESEARCH_DESIGN.md`는 같은 날의 작업 기록이며, 그 앞부분의 계획 중 상당수는 아래 결과로 수정되거나 폐기되었다.

상태 표기:
- **확인**: 정확한 계산 또는 짧은 증명으로 확인
- **수치**: 수치 탐색으로만 확인, 증명이 없다
- **선행**: 기존 문헌에 이미 있다
- **반증**: 검토 결과 성립하지 않는다
- **미정**: 판단에 필요한 작업이 남았다

## 1. 한 문단 요약

비표본 지역의 실제 유한모집단 평균에 대한 예측구간을 다룬다. 지금까지 확인한 것은 다음과 같다.
- (a) 조사 관측 깊이가 제한되면 분포 모양을 식별할 수 없다는 정확한 반례가 있다.
- (b) 잡음 섞인 보정 점수에서 잠재 목표로 넘어가는 log-concave 역합성곱 축소(LDC)를 수치로 계산했다.
- (c) split conformal의 Beta 법칙을 이용해 주변 보장을 정확히 계산했다.
- (d) apipop 유한모집단에서 LDC, noisy conformal, Fay–Herriot를 비교했다.

**표준 FH는 apipop 네 조건에서 명목 포함률을 지키고 LDC보다 12–17% 짧았다.** 그래서 “LDC가 FH의 더 나은 대체재”라는 주장은 지금 근거로 성립하지 않는다. 정규 구간의 모양 강건성 수치(87.75%)는 **대칭 log-concave에 대해 이미 알려진 결과(Barthe–Koldobsky)**다. 남은 새로움 후보는 잡음 섞인 보정자료에서 잠재 목표의 포함확률로 넘어가는 부등식과 그 유한표본 보장, 그리고 “어떤 조사 정보가 있어야 어떤 신뢰성이 가능한가”라는 질문이다. 논문을 두 편으로 나누는 결정은 **보류**한다.

**조건부 신뢰성 비교(E12–E13) 이후의 판단.** 같은 목표 Pr_D[Pr(θ_new ∈ C | D) ≥ .90] ≥ .95를 부과하면 다음과 같다.
- **FH_PAC:** 모수 bootstrap 허용계수를 쓴 FH로, 가장 짧다. 다만 비정규 모양과 apipop 두 조건에서 목표에 못 미친다.
- **LDC_PAC:** 모든 설정에서 목표를 지키지만 FH_PAC보다 11–20% 넓다.
- **오라클로 폭을 맞춘 비교:** 중심·척도를 어떻게 추정하든 폭이 거의 같다. 따라서 차이는 구간 모양이 아니라 **보장을 얻는 방식의 여유**(최악 경우 축소와 Beta 여유, LDC_PAC에서 약 15%)에서 나온다.

연구의 중심 질문은 “보장을 유지하면서 이 여유를 얼마나 줄일 수 있는가, 줄일 수 없다면 그 하한은 무엇인가”로 옮겨 간다.

### 반증되었거나 철회한 주장
- “설계 혼합이 비표본 지역 구간을 짧게 만든다” → C6에서 반증(작은 모형 한정).
- “log-concave 인증으로 noisy CP보다 10% 이상 짧다” → apipop에서 4–8%(C15).
- “기존 방법(FH)은 실제 평균에 대한 보장이 없어 실패한다” → apipop에서 반증(C16).
- “87.75%와 절단 지수 극값은 새로운 결과” → 선행 결과(C8, C9).
- “LDC 부등식은 높은 신규성이 있어 별도 이론 논문이 된다” → **판단 보류**(C10). 대칭 경우의 r = 1은 선행(C26).
- “LDC가 noisy CP보다 짧은 것은 더 나은 구간 모양 때문” → 같은 신뢰성으로 맞추면 LDC가 오히려 1–8% 넓다(C23). LDC의 이득은 보장을 유지하면서 CP_PAC보다 짧다는 데 있다.
- “FH는 조건부로 신뢰할 수 없다” → 표준 FH는 주변 목표이므로 당연하다. 같은 조건부 목표를 부과한 FH_PAC는 대부분 목표를 지키고 가장 짧지만, 비정규 모양과 apipop 두 조건에서 미달했다(C22, C24).
- “FH가 실패한다면 원인은 모양이 아니라 분산 추정이다” → 참 중심·분산 구간에 대한 C9만으로는 말할 수 없다. 추정된 FH 구간의 실패 원인은 별도 분석이 필요하다.
- “model assistance가 D/A를 낮춰 위험을 없앤다” → 표본오차는 줄일 수 있다. 잔차의 지역 간 분산 A, 중심 추정오차, 분산 추정 불확실성도 함께 확인해야 한다.

## 3. 다음 작업 (2026-09-23 갱신)

이전 3절의 세 가지(선행연구 대비, 같은 신뢰성의 FH 비교, 조건부 포함확률 검증)는 C21–C26으로 1차 수행했다. 남은 것:

1. **LDC 정리의 엄밀화.** [−M, M] 절단 극한과 Dirac을 포함한 localization 증명을 쓴다. r_α ≤ 1이 성립하는 (α, x) 범위를 정리한다. 표 전체를 적응 적분으로 다시 계산하고(C25에서 x = .001 값이 구적 오차로 드러남), Lipschitz 여유를 더해 인증된 표를 만든다. 같은 x에서 대칭 log-concave의 sharp 값을 계산해, 비대칭이 r을 얼마나 키우는지 확인한다.
2. **보장 여유 줄이기.** LDC_PAC의 여유 약 15%를 분해한다: (a) Beta PAC 여유, (b) log-concave 최악 경우 축소, (c) D 하한(η = .01). 줄일 방법 후보는 비대칭 정도에 대한 추가 제약이나 관측 가능한 모양 통계량이다. 대칭이 식별되면 r = 1보다 작은 대칭 sharp 값을 쓸 수 있다.
3. **이질 D_c의 이론.** LDC와 LDC_PAC의 보장은 공통 D 가정이다. 이질 D에서는 점수를 표준화하거나 D로 층을 나누는 규칙과 그 보장을 정리한다.
4. **FH_PAC의 실패 조건.** 어떤 모양과 D/A에서 FH_PAC가 목표에 못 미치는지 경계를 그린다. 이것이 JSSAM 독자에게 “언제 보장형 규칙이 필요한가”를 말해 준다.
5. **가장 가까운 두 연구(Cohen–Goldberger–Tirer 2025, Zhang–Tuoto 2026) 원문 정독.** 그 뒤 PUMS 확장을 붙인다.

**유망한 연구 목표(가설, 갱신):** 관측할 수 없는 지역 목표에 대해 잡음 섞인 조사자료만으로 조건부 신뢰성을 **보장**하는 최소 폭, 그리고 FH처럼 모형에 기대는 규칙과의 폭 차이(현재 11–20%)가 어디서 오며 어디까지 줄어드는가.
