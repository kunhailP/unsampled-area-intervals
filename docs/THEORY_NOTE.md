# 잡음 관측에서 잠재 포함확률로: 이론 메모

작성: 2026-09-24. Biometrika Miscellanea 후보의 수학적 핵심을 정리한다. 상태 표기는 `FINDINGS.md`와 같다: **증명**(여기에 증명 또는 증명 스케치가 있음), **수치**(계산 근거만 있음), **추측**.

## 0. 문제

W는 잠재 잔차(비표본 지역의 참값 − 중심)이고 V = W + e, e ~ N(0, D)는 W와 독립이다. 임계값 t로 척도를 맞춰 t = 1, x = D/t²로 둔다. 관측으로 확인할 수 있는 것은 noisy 포함확률 P(|V| ≤ 1) ≥ p이고, 원하는 것은 잠재 포함확률 P(|W| ≤ s) ≥ q다. log-concave 분포 집합을 LC라 하면 최선의 보정은

  R_{p,q}(x) = sup { Q_q(|W|) : W ∈ LC, P(|W + √x Z| ≤ 1) ≥ p },  Z ~ N(0, 1)

이다. 반폭 t·R_{p,q}(D/t²)는 이 정보만으로 보장되는 가장 짧은 반폭이며, 더 짧으면 어떤 LC 분포에서 실패한다. “최선”은 이 가정과 이 제약 아래에서의 뜻이다. 보정자료 전체를 쓰는 모든 절차 중 최적이라는 뜻은 아니다.

기준선: Anderson(1955)에 따라 W가 대칭 단봉이면 P(|W+e| ≤ 1) ≤ P(|W| ≤ 1)이므로 대칭 부분족에서는 R_{q,q} ≤ 1이다(Einbinder et al. 2024, Prop. 1과 같은 내용). 모양 가정이 없으면 s = 1 + √x z_{1−(p−q)/2}가 안전하다(`FINDINGS.md` C28).

## 1. 극값의 축소 — **증명**

**명제 1.** R_{p,q}(x)는 Dirac 질량과 “한 구간 [a, b] 위의 log-affine 밀도 ∝ e^{βw}”들에 대한 sup과 같다(가족 𝓕).

증명. 𝓕 ⊂ LC이므로 ≥는 자명하다. ≤를 보이기 위해 W ∈ LC가 가능하고(E g(W) ≥ p, g(w) = P(|w + e| ≤ 1)) s < Q_q(|W|)라 하자. 그러면 어떤 γ > 0에 대해 P(|W| < s) ≤ q − γ다.
1. **절단(수준 손실 없음).** g는 연속이고 |w| → ∞에서 0으로 간다. M ≥ s를 g(w) ≤ p(|w| ≥ M)가 되도록 크게 잡고, W_M = W | {|W| ≤ M}(LC), ε_M = P(|W| > M)로 둔다. E[g(W); |W| > M] ≤ p ε_M이므로 E g(W_M) ≥ (p − pε_M)/(1 − ε_M) = p다. 즉 조건부화는 g가 평균보다 작은 곳만 잘라내므로 제약을 해치지 않는다. 또 P(|W_M| < s) ≤ (q − γ)/(1 − ε_M)이고, M이 크면 이는 q보다 작다.
2. **localization.** K = [−M, M]에서 f = g − p는 연속이고, Φ(μ) = −μ((−s, s))는 선형이며 약위상에서 상반연속이다(열린 집합의 질량은 하반연속). Fradelizi–Guédon(2004, Discrete Comput. Geom. 31, 327–335; s = 0)에 따르면 {μ ∈ LC(K) : ∫ f dμ ≥ 0} 위에서 Φ의 sup은 Dirac 또는 구간 위 log-affine 측도에서 달성된다. 따라서 F ∈ 𝓕가 존재해 ∫ g dF ≥ p이고 F((−s, s)) ≤ P(|W_M| < s) < q, 즉 Q_q(|F|) ≥ s다.
3. s < Q_q(|W|)는 임의였으므로 Q_q(|W|) ≤ sup_𝓕 Q_q(|F|)다. ∎

이전 판은 절단에서 수준을 p − ε_M로 잃는다고 보고 p에 대한 연속성이 필요하다고 적었다. 1단계처럼 M을 g(M) ≤ p가 되게 잡으면 손실이 없다. 같은 논법이 혼합 커널(4절)에도 그대로 적용된다(ḡ도 연속이고 무한대에서 0).

**명제 2(닫힌 식).** 밀도 ∝ e^{βw} on [a, b]에 대해

  ∫_a^b e^{βw} Φ((c−w)/√x) dw = β⁻¹[ e^{βb}Φ((c−b)/√x) − e^{βa}Φ((c−a)/√x) + e^{βc+β²x/2}{Φ((b−c−βx)/√x) − Φ((a−c−βx)/√x)} ]

(부분적분). 따라서 noisy 질량과 |W|의 분위수는 Φ만으로 계산된다. 구현 `src/uai/extremal.py`는 로그 공간에서 계산하며 적응 적분과 9×10⁻¹² 이내로 일치한다.

**명제 3(2차원 축소).** 모양 (β, ℓ = b − a)을 고정하고 이동 c만 바꾸면, c ↦ P(|W + c + e| ≤ 1)과 c ↦ P(|W + c| ≤ s)는 모두 LC 함수의 합성곱이라 log-concave다(Prékopa). 따라서 가능한 c는 구간을 이루고 Q_q(|W + c|)는 c에 대해 준볼록이므로, 최댓값은 구간의 두 끝점 중 하나에서 나온다. 그래서 R은 (β, ℓ) 2차원에서의 최대이며, 각 점의 값은 근 찾기 두 번과 닫힌 식으로 얻는다. 최적화기가 필요 없고, 격자와 Lipschitz 여유로 인증된 상한을 만들 수 있다(**남은 일**).

## 2. 작은 잡음 법칙 — **증명**(비점근 상한과 점근 하한), 상수는 1차원 식의 **수치**값

이 절의 결과는 명제 1(localization)을 쓰지 않는다. LC 분포의 누적분포함수가 log-concave라는 사실, 이동·척도 불변성, 절단만 쓴다.

척도화한 한쪽 문제를 다음과 같이 둔다(Z ~ N(0, 1)).

  c_{p,q} = sup{ F_Y⁻¹(q) : Y ∈ LC, P(Y + Z ≤ 0) ≥ p },  c_q = c_{q,q}

지수꼬리족 Y_{u,b} = b − E, E ~ Exp(u)에 대해 다음이 성립한다.

  κ_u(b) := P(Y_{u,b} + Z ≤ 0) = Φ(−b) + e^{−ub+u²/2}Φ(b − u)

κ_u는 b에 대해 연속이고 엄격히 감소한다(도함수 −u e^{−ub+u²/2}Φ(b−u)). 그래서 κ_u(b) = p의 해 b_u(p)가 하나 있고, 이는 p에 대해 연속이다. F_{Y_{u,b}}(y) = min(e^{−u(b − y)}, 1)이므로 q-분위수는 b − ln(1/q)/u다. 이 분위수를 v_u(p, q) := b_u(p) − ln(1/q)/u로 둔다.

**보조정리 A(한쪽 문제의 극값은 지수꼬리, 증명).** 모든 p, q ∈ (0, 1)에 대해 c_{p,q} = sup_{u>0} v_u(p, q)다. p = q이면 이는 정리 4의 식이다.

증명.
1. (≥) 지수꼬리 분포는 LC이고 제약을 등호로 만족한다.
2. (≤) Y ∈ LC가 가능하다고 하자. Dirac Y = d이면 Φ(−d) ≥ p이므로 값 d ≤ −Φ⁻¹(p)이다. 이 값은 u → ∞의 극한 lim v_u로 얻어진다. 그 밖의 LC 분포는 밀도가 있고 F = F_Y는 연속이며 log F는 오목하다(Prékopa).
3. v = F⁻¹(q), G(y) = F(v + y)로 두면 G(0) = q이고, 0은 {G > 0}의 내점이다. 오목함수는 내점에서 초기울기를 가지므로 u := (log G)′₊(0) ≥ 0에 대해 모든 y에서 log G(y) ≤ ln q + uy다. u = 0이면 G ≤ q < 1이 되어 G(∞) = 1과 모순이므로 u > 0이다.
4. 따라서 G(y) ≤ G_u(y) := min(q e^{uy}, 1)이다. G_u는 b₀ = ln(1/q)/u인 Y_{u,b₀}의 CDF이고, 다음이 성립한다.

  p ≤ P(Y + Z ≤ 0) = E G(−v − Z) ≤ E G_u(−v − Z) = κ_u(v + b₀)

5. κ_u가 감소하므로 v + b₀ ≤ b_u(p), 즉 v ≤ v_u(p, q)다. ∎

**보조정리 B(대각선 단조성, 증명).** q′ > q이면 c_{q′} ≤ c_q다.

증명. Y가 (q′, q′)에서 가능하고 v = F_Y⁻¹(q′)라 하자. 왼쪽 질량 m_L = (q′ − q)/(1 − q)을 잘라낸 Y* = Y | Y ≥ F_Y⁻¹(m_L)도 LC다. 이 Y*에 대해 P(Y* + Z ≤ 0) ≥ (q′ − m_L)/(1 − m_L) = q이고 F_{Y*}(v) = q다. Dirac의 값 −Φ⁻¹(q′)는 −Φ⁻¹(q) ≤ c_q보다 작다. ∎

**정리 5(비점근 상한, 증명).** 모든 q ∈ (0, 1)과 모든 x > 0에 대해 R_{q,q}(x) ≤ 1 + c_q √x다.

증명.
1. W ∈ LC, e ~ N(0, x)가 W와 독립이고 P(|W + e| ≤ 1) ≥ q라 하자. 바깥으로 새는 질량 α_R = P(W + e > 1), α_L = P(W + e < −1)에 대해 α_L + α_R ≤ 1 − q다.
2. 오른쪽: Y = (W − 1)/√x ∈ LC이고 P(Y + Z ≤ 0) = 1 − α_R =: q_R ≥ q다. c의 정의와 보조정리 B에서 F_Y⁻¹(q_R) ≤ c_{q_R} ≤ c_q다. 따라서 s = 1 + c_q√x에서 P(W ≤ s) ≥ q_R, 즉 P(W > s) ≤ α_R다.
3. 왼쪽: −W ∈ LC이고 −e는 같은 분포이므로, 같은 논법에서 P(W < −s) ≤ α_L다.
4. 두 쪽을 합하면 P(|W| ≤ s) ≥ 1 − α_L − α_R ≥ q, 즉 Q_q(|W|) ≤ s다. ∎

요점은 양쪽 문제의 실패 예산이 두 한쪽 문제로 나뉘고, 한쪽 문제는 명제 5′에 따라 모든 D에서 정확하다는 것이다. 각 쪽의 수준 1 − α ≥ q에서 드는 비용은 보조정리 B에 따라 c_q 이하다.

**정리 5+(p ≥ q, 증명).** 모든 x > 0에 대해 R_{p,q}(x) ≤ 1 + √x · C_{p,q}다. 여기서

  C_{p,q} = sup_{α_L+α_R = 1−p} inf_{β_L+β_R = 1−q} max( c_{1−α_L, 1−β_L}, c_{1−α_R, 1−β_R} )

이다. 증명은 정리 5와 같다. 각 쪽에서 P(Y + Z ≤ 0) ≥ 1 − α이면 F_Y⁻¹(1 − β) ≤ c_{1−α,1−β}이고, c_{p′,q′}가 p′에 대해 감소하므로 sup은 합이 1 − p인 경계에서 나온다. 한쪽에 예산을 몰면(α_L = β_L → 0) C_{p,q} ≥ c_{p,q}다. 수치로는 C_{p,q} = c_{p,q}였다. 즉 최악의 배분은 한쪽 몰기다(C_{.9036,.90} = −.0572).

**따름정리 5B(bi-log-concave 확장, 증명; 외부 검토 제안).** 𝓑를 점질량 또는 연속 CDF F에서 log F와 log(1 − F)가 모두 오목한 분포의 모임이라 하자(Dümbgen–Kolesnyk–Wilke 2017, JSPI 184). LC ⊂ 𝓑이고 𝓑는 다봉 밀도를 허용한다. 보조정리 A의 증명은 q-분위수에서 log F_Y의 초기울기만 쓰므로, log F_Y가 오목한 모든 Y에서 같은 상한이 성립한다. 지수꼬리가 LC에 있으므로 c_{p,q}는 𝓑에서도 같다. 정리 5와 5+의 오른쪽 논법은 log F_W, 왼쪽 논법은 log(1 − F_W)의 오목성(F_W 연속)만 쓴다. 정리 4의 하한 극값열은 LC ⊂ 𝓑에 있다. 따라서 R^𝓑_{p,q}(x) ≤ 1 + C_{p,q}√x(p ≥ q, 모든 x)이고 R^𝓑_{q,q}(x) = 1 + c_q√x + o(√x)이며, 따름정리 6도 𝓑에서 성립한다. 명제 1(localization)과 인증 표는 밀도의 log-concavity를 쓰므로 옮겨지지 않는다.

**정리 4(점근 하한, 증명).** R_{q,q}(x) ≥ 1 + c_q √x − o(√x)다.

증명.
1. ε > 0을 두고 v_u(q, q) > c_q − ε인 u를 고른다(보조정리 A). p′ ∈ [q, (1 + q)/2]에서 b_u(p′) ≥ b_min이다.
2. Y = Y_{u, b_u(p′)}, W = 1 + √x Y ∈ LC로 둔다. t = 2/√x이면 다음이 성립한다.

  P(|W + e| ≤ 1) = p′ − P(Y + Z < −t) ≥ p′ − η_x,  η_x := e^{−u(t + b_min)/2} + Φ(−(t + b_min)/2)

3. p′ = q + η_x로 두면 제약을 만족한다. P(|W| ≤ s) ≤ F_W(s)이고 F_W는 q 근처에서 엄격히 증가하므로 Q_q(|W|) ≥ 1 + √x v_u(q + η_x, q)다.
4. η_x → 0(지수적)이고 v_u는 p에 대해 연속이므로 liminf (R_{q,q}(x) − 1)/√x ≥ c_q − ε다. ∎

이전 판의 “−1 + δ에서 자르는” 단계는 필요 없다.

**따름정리(작은 잡음 법칙, 증명).** 모든 q에서 lim_{x→0} (R_{q,q}(x) − 1)/√x = c_q > 0이고, 상한 1 + c_q√x는 모든 x에서 성립한다. c_q > 0은 정리 4의 작은 u 전개(v_u = u/2 + o(u))에서 나온다.

수치 값(보조정리 A의 1차원 sup, 구간산술 인증은 아님): c_.80 = 0.046073, c_.85 = 0.0316, c_.90 = 0.019062, c_.95 = 0.0084075, c_.99 = 0.0014.

수치 확인:
- (0) 정확한 2차원 격자(E16 방식, β 71개 × 길이 70개)의 R_{.9,.9}는 x = 10⁻⁶, 10⁻⁵, 10⁻⁴, 10⁻³, 10⁻²에서 모두 1 + c_.9√x 이하다. 차이는 각각 −2.7×10⁻⁷, −4.4×10⁻⁷, −2.3×10⁻⁷, −6.2×10⁻⁵, −3.1×10⁻³이다. 격자값은 R의 하한이므로 모순이 없다.
- (1) R_{.9036,.9} 격자값은 x = 10⁻⁵–.061에서 모두 1 − .0572√x 이하다.

**해석.**
- 대칭이면 잡음은 항상 보수적이다(Anderson). 비대칭 log-concave에서는 **모든 수준 q에서** 잡음이 작을 때 noisy 보정이 잠재 목표를 √x 차수로 놓칠 수 있다. 다만 그 크기는 **모든 x에서** c_q√x 이하다.
- 기구: 끝점 1 바로 바깥에서 밀도가 지수적으로 올라가다 잘리는 분포(경계층 폭 √x)에서, 잡음이 바깥 질량을 안으로 끌어들이는 양이 안쪽 질량을 밖으로 내보내는 양보다 크다.
- 테일러 전개로 기대되는 차수 O(x)(f′(1) − f′(−1) 항)보다 느린 √x인 것은 그 경계층 때문이다.
- 이전 검토에서 “작은 x의 r > 1은 구적 오차”라고 한 것은 크기(1.027)에 대해서만 맞았다. 참값은 x = 10⁻³에서 약 1.0005–1.0006이다.

**따름정리 6(PAC 여유, 증명; 상수는 공 산술 인증).** 정리 5+에 따라 C_{p,q} ≤ 0이면 **모든 x에서** R_{p,q}(x) ≤ 1 + C_{p,q}√x ≤ 1이다. 즉 확대가 전혀 필요 없고 최소 √x·|C| 만큼 축소된다. C_{q+δ,q} ≤ 0이 되는 최소 여유 δ는 q = .80, .90, .95에서 4.4×10⁻³, 8.0×10⁻⁴, 1.6×10⁻⁴다. K = 110, k = 105의 Beta 여유 p_k − q = .0036(p_k = .9036은 Beta(105, 6)의 δ = .04 분위수이고, δ = .05이면 p_k = .9068)은 q = .90에서 이를 넘으므로, 균질 잡음의 PAC 절차에서는 확대가 필요 없다. 이 결론은 이제 점근이 아니며 정리 5에도 의존하지 않고 정리 5+만 쓴다. 상수는 공 산술로 인증했다(E27, FINDINGS C42): 최소 여유는 (4.3, 5.0]×10⁻³, (7.9, 10]×10⁻⁴, (1.5, 2.0]×10⁻⁴ 안에 있고, −.0571845 ≤ C_{.9036,.9} ≤ −.057이다. 정리 4의 하한 논법은 p > q에도 그대로 적용되어 R_{p,q}(x) ≥ 1 + c_{p,q}√x − o(√x)이므로, c_{q+δ,q} > 0인 여유 δ는 작은 x에서 확대를 막지 못한다. 따라서 위 구간은 "모든 x에서 R ≤ 1"이 되는 최소 여유의 구간이기도 하다. c_{p,q}, C_{p,q}는 단일 가우스 잡음에 대한 상수이므로 혼합 커널(HetLDC)에는 직접 적용되지 않는다.

**명제 5′(한쪽 전달의 정확한 닫힌 형태, 증명).** 모든 D > 0과 t ∈ ℝ에 대해

  sup{ Q_q(W) : W ∈ LC, P(W + e ≤ t) ≥ p } = t + √D · c_{p,q}.

W ↦ (W − t)/√D는 LC를 보존하므로 문제가 정확히 척도화한 한쪽 문제가 된다. 점근이 아니라 모든 D에서 정확하며, 양쪽 문제의 √x 법칙은 각 끝점 근처가 국소적으로 한쪽 문제이기 때문에 생긴다.

- c_{.9036,.90} = −.0572

## 2C. 중심 조건과 경계 전이 — **증명**, 상수는 **수치**(2026-09-27)

정리 5의 극값분포 W = 1 + √x·Y는 질량이 경계 1 근처 [1 − O(√x), 1]에 몰려 있어 평균이 거의 1이다. 이 절은 **평균의 위치가 최악 확대의 차수를 정한다**는 것을 보인다. 모든 결과는 같은 수준의 전달(p = q), 단일 noisy 제약 P(|W + √x Z| ≤ 1) ≥ q에 대한 것이다. p > q의 PAC 절차는 따름정리 6으로 이미 확대가 필요 없으므로, 이 절은 폭을 더 줄이는 결과가 아니라 √x 현상의 원인을 설명하는 결과다. EW = 0은 **잠재 잔차분포의 평균**에 대한 조건이며, 학습자료에서 잔차 평균을 0으로 맞춘 것과는 다르다.

**명제 C1(평균 조건 아래의 반경 상한, 증명).** W ∈ LC, |EW| ≤ B, Z ~ N(0, 1) 독립, r(s) = Q_q(|W + √s Z|)라 하자. 그러면 모든 s ≥ 0에서

  (r(0) − B)₊² ≤ (r(s) − B)₊² + s.

특히 t > B에서 P(|W + σZ| ≤ t) ≥ q이면 Q_q(|W|) ≤ B + √((t − B)² + σ²)이고, EW = 0이면 Q_q(|W|) ≤ √(t² + σ²)이다. 정규화하면 R^{|μ|≤b}_{q,q}(x) ≤ b + √((1 − b)² + x) = 1 + x/(2(1 − b)) + O_b(x²).

증명. s > 0에서 f_s(W + √s Z의 밀도)는 양수이고 매끄러우며 로그오목이고 평균 μ = EW를 보존한다. 평균점 부등식 ‖f_s‖∞ ≤ e·f_s(μ)(Fradelizi 1997; Fradelizi–Madiman–Wang 2016, Corollary 4.6)에서 ℓ_s = log f_s는 ℓ_s(r) − ℓ_s(μ) ≤ 1을 만족한다. 오목성으로 r > B이면 ℓ_s′(r) ≤ 1/(r − μ) ≤ 1/(r − B), ℓ_s′(−r) ≥ −1/(r + μ) ≥ −1/(r − B). H_s(r) = P(|W + √s Z| ≤ r)에 열방정식 ∂_s f_s = f_s″/2를 쓰면

  ∂_s H_s(r) = {f_s′(r) − f_s′(−r)}/2 ≤ {f_s(r) + f_s(−r)}/{2(r − B)} = ∂_r H_s(r)/{2(r − B)}.

H_s(r(s)) = q를 음함수 미분하면 r(s) > B에서 r′(s) ≥ −1/{2(r(s) − B)}, 즉 d(r − B)₊²/ds ≥ −1이다(r ≤ B에서는 0). ε에서 s까지 적분하고 ε ↓ 0으로 보낸다. 평균이 지지집합 내부에 있으므로 |W|의 분포함수는 분위수 근처에서 순증가하고 분위수가 수렴한다. δ_0은 자명하다. □

- 원래 밀도의 꺾임이나 지지집합 끝을 허용한다(s > 0에서 평활화한 뒤 극한).
- 분위수의 열방정식 진화(Steinbrecher–Shaw 2008)와 평균점 부등식은 알려진 도구다. 새로운 것은 결합의 결과, 즉 **분포군 전체에 공통인** 비점근 상한이다. 고정된 매끄러운 분포의 O(x) 편향 전개(Jochmans–Weidner 2024)는 분포마다 계수와 나머지항이 달라 이 상한을 주지 않는다.
- median 0으로는 바로 옮겨지지 않는다. 가우스 합성곱은 평균은 보존하지만 중앙값은 보존하지 않는다. bi-log-concave로도 옮겨지지 않는다(합성곱 보존을 쓴다).

**명제 C2(평균 0에서도 x 차수의 확대는 필요, 증명).** X의 밀도가 [0, ℓ]에서 e^{βX}에 비례(β > 0)하고 W = X − EX이며, r₀ = Q_q(|W|)가 지지집합 내부에 있으면, 노이즈 분산 v ↓ 0에서 t(v) = Q_q(|W + √v Z|) = r₀ − (β/2)tanh(βr₀)v + o(v)이다. W/t(v)로 정규화하고 x = v/t(v)²로 두면

  r₀/t(v) − 1 = (βr₀/2)·tanh(βr₀)·x + o(x).

±r₀ 근처에서 f′ = βf이므로 명제 C1 증명의 등식에서 바로 나온다. 모든 q ∈ (0, 1)에서 β를 충분히 작게 잡으면 r₀가 내부에 온다. 따라서 **R^0_{q,q}(x) − 1 = Θ(x)**이다. 대칭이 아니면 평균이 0이어도 확대가 필요하다. 이는 Einbinder 등(2024)의 대칭 조건과 평균 조건이 다르다는 것을 보여준다.

**명제 C3(경계 접근의 필요조건, 증명).** q > 1 − 1/e, W ∈ LC, P(|W + √x Z| ≤ 1) ≥ q이고 δ = Q_q(|W|) − 1 > 0이면 |EW| < 1이고

  2(1 − |EW|)δ + δ² ≤ x.

따라서 δ ≥ a√x(a ∈ (0, 1) 고정)이면 1 − |EW| ≤ (1 − a²)√x/(2a)다. 즉 **√x 차수의 손실은 평균이 경계에서 O(√x) 이내로 올 때만 가능하다.**

증명. V = W + √x Z의 분포함수 F는 log F와 log(1 − F)가 오목하다. F(V) ~ U(0, 1)이라 E log F(V) = −1이고, Jensen으로 F(EV) ≥ 1/e, 1 − F(EV) ≥ 1/e(1차원 Grünbaum 부등식). EW ≥ 1이면 P(|V| ≤ 1) ≤ F(EW) ≤ 1 − 1/e < q로 모순이다(−1 쪽도 같다). 명제 C1을 B = |EW|, t = 1로 쓰고 제곱한다. □

**보조정리 C4(평균 제약이 있는 한쪽 문제, 증명).** a = log(1/q), A = 1 − a, b_u = b_u(q), v(u) = b_u − a/u, k(u) = 1/u − b_u라 하자. q > 1 − 1/e, κ ≥ 0이면

  S_q(κ) = sup{Q_q(Y) : Y ∈ LC, EY ≤ −κ, P(Y + Z ≤ 0) ≥ q} = L_q(κ) := sup{v(u) : k(u) ≥ κ} > 0.

증명. 보조정리 A처럼 Y의 q-분위수 v₀에서 log F_Y의 초기울기 u > 0을 잡으면 F_Y(y) ≤ min{qe^{u(y−v₀)}, 1}이고, 오른쪽은 Y′ = b − E_u(b = v₀ + a/u)의 분포함수다. Y′ ≤_st Y이므로 EY′ ≤ EY ≤ −κ, noisy 제약도 보존되고, 분위수는 v₀ 그대로다. 즉 지수꼬리 대체가 **평균 제약도 보존한다.** 지수꼬리에서 두 제약은 b ≤ b_u, b ≤ 1/u − κ이므로 값은 min{v(u), A/u − κ}다. k(u) < κ이면 값은 A/u − κ이고, k는 연속이며 t ↓ 0에서 k(t) → ∞이므로 k(t) = κ인 t < u가 있다. 그 점의 값 A/t − κ가 더 크다(A > 0). 따라서 k(u) ≥ κ인 u만 보면 된다. 점질량은 q > 1/2에서 음의 분위수만 준다. u ↓ 0에서 v(u) ~ u/2 > 0이다. □

**정리 C5(경계 거리 κ√x에서의 전이계수, 증명).** 고정 q > 1 − 1/e, κ ≥ 0에서 R^{(κ)}_q(x) = sup{Q_q(|W|) : W ∈ LC, |EW| ≤ 1 − κ√x, P(|W + √x Z| ≤ 1) ≥ q}라 하면

  lim_{x↓0} {R^{(κ)}_q(x) − 1}/√x = L_q(κ).

하한. 정리 5 하한의 W = 1 + √x(b − E_u)는 평균이 1 − k(u)√x다. 먼 끝 누출을 메우려고 b를 o(1)만큼 줄이는 조정은 평균을 더 줄이므로 k(u) ≥ κ이면 평균 제약이 유지된다.

상한. x_n ↓ 0, h_n = √x_n, 거의 최적인 W_n을 잡고 (r_n − 1)/h_n ≥ a₀ > 0인 부분수열만 보면 된다. 명제 C3으로 κh_n ≤ 1 − |EW_n| ≤ Kh_n(K = (1 − a₀²)/(2a₀))이다. 부호를 바꿔 EW_n ≥ 0으로 두고 Y_n = (W_n − 1)/h_n이라 하면 −K ≤ EY_n ≤ −κ다. T_n = Y_n + Z의 분포함수 F_n, 최대 밀도 M_n에 대해 F_n(0) ≥ q, F_n(ET_n) ≤ 1 − 1/e이므로 ε_q = q − (1 − 1/e) ≤ M_n K다. 매끄러운 로그오목 밀도는 Mσ ≤ √2를 만족한다(분위수 밀도의 오목성으로 g(중앙값) ≥ M/2, 꼬리 P(|T − m| > t) ≤ e^{−2g(m)t}). 따라서 Var Y_n = Var T_n − 1 ≤ 2K²/ε_q²으로 공통 유계다. 부분수열 극한 Y는 로그오목(점질량 포함)이고 균등적분가능성으로 EY ≤ −κ, EΦ(−Y) ≥ q다. (|W_n| − 1)/h_n은 W_n ≥ 0에서 Y_n과 같고 예외 확률은 0으로 가므로 분위수가 수렴해 Q_q(Y) ≤ S_q(κ) = L_q(κ)다. □

**2C′. bi-log-concave로의 확장과 간소화한 증명(2026-09-28).** 𝓑를 점질량이거나 연속 분포함수 F에 대해 log F와 log(1 − F)가 오목한 법칙의 집합이라 하자(Dümbgen–Kolesnyk–Wilke 2017). LC ⊂ 𝓑이고 𝓑는 다봉 법칙을 포함한다. 쓰는 선행 사실은 셋이다. (i) 비퇴화 𝓑 법칙은 지지구간 내부에서 양의 밀도를 갖고, 매끄러우면 −f²/(1 − F) ≤ f′ ≤ f²/F(DKW Theorem 1). (ii) 𝓑 법칙과 LC 법칙의 합성곱은 𝓑(Saumard 2019, ECP 24, 합성곱 보존 명제). 특히 가우스 평활화가 𝓑를 보존한다. (iii) 점질량을 포함한 𝓑는 약수렴에 닫혀 있다(같은 논문).

- **평균 근처 score(평균점 부등식 대체).** 매끄럽고 양의 밀도를 가진 X ∈ 𝓑, 평균 μ, t > μ, h = f(t)/F(t)라 하자. log F의 접선으로 F(y) ≤ min{F(t)e^{h(y − t)}, 1}이고 오른쪽은 X′ = t − log F(t)/h − E_h의 분포함수다. X′ ≤_st X이므로 μ ≥ E(X′) = t − {1 + log F(t)}/h, 즉 h(t − μ) ≤ 1 + log F(t) ≤ 1. (i)의 f′/f ≤ f/F와 합치면 (log f)′(t) ≤ 1/(t − μ)(t > μ). −X에 적용하면 (log f)′(t) ≥ −1/(μ − t)(t < μ). 이 논증은 log f의 오목성을 쓰지 않으므로 명제 C1의 증명에서 Fradelizi의 평균점 부등식을 대신한다.
- **명제 C1은 𝓑에서 성립한다.** (ii)로 W + s^{1/2}Z ∈ 𝓑, 평균 보존, 매끄럽고 양의 밀도. 위 score 부등식이 명제 C1 증명의 두 부등식을 그대로 준다. ε ↓ 0의 극한은 (i)의 내부 양의 밀도로 성립한다.
- **최대 밀도의 절반(Bobkov 오목성 대체).** 매끄러운 𝓑 밀도 g, 중앙값 m, 최댓값 M. hazard g/(1 − F)는 비감소, reverse hazard g/F는 비증가이므로 y ≤ m이면 g(m) = 2 · g(m)/{2(1 − F(m))} ≥ g(y)/{2(1 − F(y))} ≥ g(y)/2, y ≥ m도 대칭으로 같다. 따라서 g(m) ≥ M/2이고, 중앙값에서의 접선으로 pr(|T − m| > y) ≤ e^{−2g(m)y}, var(T) ≤ 1/{2g(m)²} ≤ 2/M². 정리 C5 상한의 tightness 단계에서 Bobkov(1996)의 분위수 밀도 오목성을 대신한다.
- **명제 C3과 정리 C5도 𝓑에서 성립한다.** C3의 Jensen 단계는 log F, log(1 − F)의 오목성만 쓴다. C5의 하한 구성은 LC 법칙이라 𝓑에도 하한이다. 상한은 위 분산 부등식, (iii)의 약수렴 닫힘, 보조정리 C4(log F_Y의 접선만 씀)로 그대로 간다.
- **명제 C2(평균 0의 Θ(x))**는 구성이 LC이므로 𝓑의 하한이기도 하다.
- **옮겨지지 않는 것.** 명제 1의 localization, 유한 x의 인증 반경, 명제 D1(경계 근처 축소 법칙)은 밀도의 로그오목성을 쓴다. 따라서 가정은 결과별로 나뉜다: **언제 안전한가(정리 5, C1–C5)는 𝓑, 얼마나 줄일 수 있는가(명제 1, 인증, D1)는 LC.**

Anderson 정리의 단봉 조건이 필요하다는 뜻이며, 원고의 “symmetric and unimodal” 표현이 맞다. 같은 족(위상 0, π/2 평균 제거)에서 명제 C1의 부등식은 q ∈ {.3, .7, .9}, s ∈ {10⁻³, .1, 1}에서 모두 성립했다(`test_core.py`).

x_p = 1/z², z = Φ⁻¹{(1 + p)/2}는 잡음만으로 [−1, 1]의 포함확률이 p가 되는 x다(x > x_p이면 가능한 법칙이 없다). 인증 표(C39)에서 x가 x_p에 가까워지면 R_{p,q}(x)는 0으로 가며, q = .9에서 R/√(x_p − x)는 거의 일정했다(1.83–1.86). 이 절은 그 상수를 로그오목 분포의 분위수-적률 상수로 정확히 밝힌다. 따름정리 6의 해석적 축소 1 − .057√x는 인증된 축소의 일부만 설명한다(x = .1, .2, .3에서 약 19%, 10%, 6%). 이 절의 결과가 나머지를 설명한다.

**정의.** 척도에 닫힌 분포류 𝒞에 대해 M^𝒞_q = sup{Q_q(|W|)/E(W²)^{1/2} : W ∈ 𝒞, W ≠ 0}. 로그오목류 M_q는 한 선형 제약 E(W²) ≤ 1 아래 선형 목적 pr(|W| < s)의 극값 문제라 명제 1과 같은 localization으로 한 구간 위 log-affine 법칙에서 계산된다(제약 E(W²)은 |W|에 대해 증가하므로 [−M, M] 조건부화가 제약을 지킨다).

| q | 가우스 z_{(1+q)/2} | 대칭 로그오목(C8, Barthe–Koldobsky) | 로그오목 M_q | 모양 가정 없음 (1 − q)^{−1/2} |
|---|---|---|---|---|
| .80 | 1.2816 | 1.3995 | 1.4430 | 2.2361 |
| .90 | 1.6449 | 1.7558 | 1.8532 | 3.1623 |
| .95 | 1.9600 | 2.1691 | 2.3481 | 4.4721 |

q = .9의 극값은 기울기 β ≈ 2.164, 구간 [−.8335, .1665]의 log-affine 법칙(경계 쪽으로 올라가는 비대칭 밀도)이다. 모양 가정 없는 값은 두 점 법칙(Chebyshev)이다.

**명제 D1(가능성 경계 근처의 축소, 증명).** 0 < p, q < 1. x ↑ x_p일 때

  R_{p,q}(x) = M_q (x_p − x)^{1/2}{1 + o(1)}.

모양 가정 없는 류에서는 같은 식이 (1 − q)^{−1/2}로 성립한다(보충 명제 S2의 날카로운 Markov 반경을 전개하면 된다).

증명. ε = g_x(0) − p, κ = −∂²_w g_x(0) = 2φ(x^{−1/2})x^{−3/2}. g_x(w)는 (x, w)에 대한 열방정식 ∂_x g = ∂²_w g/2를 만족하므로 ∂_x g_x(0) = −κ/2이고, ε = (κ/2)(x_p − x){1 + O(x_p − x)}, 즉 2ε/κ = (x_p − x){1 + o(1)}이다. g_x는 w에 대해 대칭이고 매끄러우므로 g_x(0) − g_x(w) = (κ/2)w²{1 + O(w²)}이며, x가 x_p 근처의 콤팩트 범위에 있을 때 균등하다.
- 상한. W가 가능하면 E{g_x(0) − g_x(W)} ≤ ε. 고정 w₀ > 0에 대해 |w| ≥ w₀에서 g_x(0) − g_x(w) ≥ c₀ > 0이므로 pr(|W| ≥ w₀) ≤ ε/c₀ → 0. 로그오목이면 질량의 대부분이 폭 O(ε^{1/2}) 안에 있으므로 꼬리는 그 척도의 지수로 감소하고 E(W²; |W| > w₀)는 ε보다 지수적으로 작다. 따라서 E(W²) ≤ (2ε/κ){1 + O(w₀²) + o(1)}이고, w₀ → 0으로 보내면 E(W²) ≤ (x_p − x){1 + o(1)}. M_q의 정의로 Q_q(|W|) ≤ M_q E(W²)^{1/2}.
- 하한. 유계 지지의 W* ∈ LC, E(W*²) = 1, Q_q(|W*|) ≥ M_q − η를 잡고(구간 log-affine 극값족), λ² = (x_p − x)(1 − η)로 W = λW*라 하면 E g_x(W) = g_x(0) − (κ/2)λ² + O(λ⁴) = p + (κ/2)(x_p − x)η + o(x_p − x) ≥ p. Q_q(|W|) = λQ_q(|W*|). η ↓ 0. □

**이질 잡음과 분산 예산(명제 D2, 점근은 증명; 정확도는 수치).** 평균 커널 ḡ(w) = K⁻¹Σ g_{x_i}(w)에 대해 c*를 K⁻¹Σ g_{x_i + c*}(0) = p의 해(“잠재 분산 예산”, W가 N(0, c*)이면 noisy 포함률이 정확히 p)로 두면, 각 성분이 열방정식을 따르므로 2{ḡ(0) − p}/|ḡ″(0)| = c*{1 + O(c*)}이고 같은 증명으로 c* → 0일 때 R^mix = M_q c*^{1/2}{1 + o(1)}. 동질 잡음에서 c* = x_p − x다.

원 단위 해석: s ≈ M_q (t²/z² − D)^{1/2}. noisy 임계값에서 잡음 분산을 빼 잠재 이차적률을 얻고, 가우스 분위수 z_{(1+q)/2} 대신 로그오목 최악 상수 M_q를 곱한다. 모양 가정의 값은 상수의 비로 읽힌다: 경계 근처에서 로그오목은 모양 가정 없는 반경을 1.71배(q = .9), 대칭은 추가로 5% 줄인다.

**근사로서의 정확도(E33, `results/edge.json`, 수치).**
- 동질(p = .9, .9036): x ≥ .1에서 인증된 가능값 L과 M_q(x_p − x)^{1/2}의 비가 [.955, 1.0003]. x = .2에서 1.2%, .25에서 .5%, .3에서 .05% 차이. x = .05에서는 근사가 7.7% 크고(1.035 대 .961), x → 0에서는 z_p/M_q로 12.7% 크다. 경계 바로 앞(x ≈ .34)에서 L이 근사를 8×10⁻⁵만큼 넘으므로 **전역 상한은 아니다.**
- 이질(E20 자료 160개, 평균 x̄ ≈ .1): T·M_q c*^{1/2}가 절차의 격자 반경보다 4.0–7.8% 크다(모두 보수적 방향). 곡률형 2{ḡ(0) − p}/|ḡ″(0)|는 같은 자료에서 약 2배 커서 쓸 수 없다.

**의미.** 작은 x 쪽은 정리 5·C1–C5(확대 여부와 차수가 평균 위치에 달림), 큰 x 쪽은 명제 D1(축소의 크기가 로그오목 분위수-적률 상수로 정해짐)이 R(x)의 양 끝을 해석적으로 규정한다. 두 영역 사이(대략 .01 < x < .1)는 인증 계산에 의존한다. 닫힌형 M_q c*^{1/2}는 보장이 아닌 근사이므로 절차에는 인증 반경을 쓰고, 근사는 해석과 설계(필요한 표본 깊이 등)에 쓴다.

## 4. 이질 잡음 — 절차는 **증명**, 크기는 **수치**

지역 i의 잡음이 N(0, D_i)이고 D_i가 알려져 있다(FH 관행). V_i는 독립이지만 동일분포가 아니다.

**명제 7(순서통계량의 Beta 하한은 이질 잡음에서도 유효).** F̄를 |V_i|의 평균 CDF라 하고 T = |V|_(k), t_p = F̄⁻¹(p)라 하자. {F̄(T) < p} = {#{|V_i| ≤ t_p} ≥ k}이고, 이 개수는 평균 Kp인 Poisson-binomial이다. Hoeffding(1956)에 따라 c ≥ Kp + 1이면 P(PoisBin ≥ c) ≤ P(Bin(K, p) ≥ c)이므로, p_k = Beta(k, K+1−k)의 δ 분위수에 대해 P(F̄(T) ≥ p_k) ≥ 1 − δ다(k ≥ Kp_k + 1일 때; K = 110, k = 105, p_k = .9036에서 성립).

**따름정리 8(HetLDC).** 그 사건 위에서 ∫ ḡ_T dG ≥ p_k이고, ḡ_T는 x_i = D_i/T²에서의 가우스 커널 평균이다. 이것도 선형 제약 하나이므로 명제 1의 극값족이 그대로이고, 반폭 s = T·R^{mix}_{p_k,q}(x_1, …, x_K)는 모든 LC G에서 잠재 포함률 ≥ q를 준다. 계산량을 줄이려고 x_i를 32개 묶음 평균으로 양자화하고, 커널 차이의 상한 ε(격자 최대 + Mh²/8)을 p_k에서 뺀다(`procedures.quantised_kernel`, 보통 ε ≈ 2×10⁻⁴). 혼합 커널은 log-concave가 아니어서 가능한 이동이 여러 구간일 수 있지만, 잠재 분위수는 이동에 대해 준볼록이므로 가장 바깥 두 끝점만 보면 된다.

**E18(평균 분산 대입의 오류 방향).** x̄와 로그정규 퍼짐 σ에서 정확한 혼합 커널의 R과 평균 분산 대입 R(x̄)를 비교하면:
- 대부분 혼합 쪽이 더 작다(대입이 보수적, 최대 .008 차이).
- x̄ = .2, σ = 1.0에서는 혼합 R = .7648 > 대입 .7542다. **평균 분산 대입은 1.4% 짧아 보장을 잃는다.**
- 반대로 “안전하게” 가장 작은 분산을 대입하면 최대 14% 넓어진다(x̄ = .136, σ = .7: .986 대 .863).

## 5. 인증된 상한 — 방법은 **증명**, 값은 부동소수점 계산(여유 10⁻⁹)

**명제 9(잡음 수준에 대한 연속성, 증명).** 모든 p, q, x ≥ 0, h ≥ 0에 대해 R_{p,q}(x + h) ≤ R_{p,q}(x) + c_q √h다. 잡음이 혼합이어도 모든 성분의 분산을 h씩 늘리는 경우 같은 부등식이 성립한다.

증명.
1. W ∈ LC가 잡음 x + h에서 가능하다고 하자. e_{x+h} = e_x + e_h(독립)로 쓰면 W′ = W + e_h는 LC이고(LC의 합성곱) 잡음 x에서 가능하다. 그래서 t := Q_q(|W′|) ≤ R_{p,q}(x)다.
2. P(|W + e_h| ≤ t) ≥ q이므로, 척도 t에서 정리 5를 쓰면 Q_q(|W|) ≤ t·R_{q,q}(h/t²) ≤ t(1 + c_q√h/t) = t + c_q√h다.
3. 혼합 잡음은 성분마다 e_h를 더한 것이 곧 전체에 독립 e_h를 더한 것이다. ∎

x = 0이면 R_{q,q}(0) = 1이므로 이것이 정리 5다. 이 명제 덕분에 격자점 x_i에서의 인증 상한 U_i가 모든 x로 넓혀진다.

  R_{p,q}(x) ≤ min_{x_i ≤ x} { U_i + c_q √(x − x_i) }

**명제 10(상자 경계, 증명).** 극값족(명제 1, β ≥ 0)을 W = b − Y로 쓴다. Y의 밀도는 [0, ℓ]에서 ∝ e^{−βy}다. 끝을 포함한다: ℓ = 0이나 β = ∞는 점질량, ℓ = ∞는 지수꼬리, β = 0은 균등이다.
1. Y는 β에 대해 우도비 순서로 감소하고, ℓ에 대해서는 같은 밀도의 절단이라 확률적으로 증가한다. 그래서 W는 β와 b에 대해 증가하고 ℓ에 대해 감소한다.
2. 상자 [β₀, β₁] × [ℓ₀, ℓ₁] × [b₀, b₁]에서 W_lo = W(β₀, ℓ₁, b₀), W_hi = W(β₁, ℓ₀, b₁)이면, 상자 안의 모든 W가 W_lo ≤_st W ≤_st W_hi를 만족한다.
3. A(W) = P(W + e ≤ 1)와 B(W) = P(W + e ≤ −1)는 모두 이 순서에서 감소한다. 따라서 다음이 성립한다.

  P(|W + e| ≤ 1) ≤ min{ A(W_lo) − B(W_hi), 2β₁/(1 − e^{−β₁ℓ₀}) },  P(|W| ≤ s) ≥ P(W_hi ≤ s) − P(W_lo ≤ −s)

  둘째 항은 최대 밀도 경계(∫g = 2)다.
4. 모든 항이 Φ의 닫힌 식이다. 앞의 경계가 p보다 작거나 뒤의 경계가 q 이상이면 그 상자는 “R ≤ s”에 반례가 없다.
5. b의 범위. b < −1 + √x Φ⁻¹(p)이면 W ≤ b이므로 불가능하다. b > 1 + k + (2 + 2k)(1 − p′)/p′(k = 7√x, p′ = p − 2Φ(−7))이면 불가능하다. 밀도가 b 쪽으로 증가하므로 P(W ∈ [−1−k, 1+k]) ≤ r/(1 + r), r = (2 + 2k)/(b − 1 − k)이기 때문이다.
6. 남는 (β, ℓ) ∈ [0, ∞]²은 u/(1 − u)로 압축한다. 가지치기(가장 넓은 변을 반으로)로 모든 상자가 제거되면 R_{p,q}(x) ≤ s다.

수치 오차. 닫힌 식은 ℓ < 10⁻⁴이나 0 < βℓ < 10⁻³에서 소거 오차가 있다(10⁻⁹ 수준). 그래서 상자 꼭짓점을 그 영역 밖으로 바깥쪽 반올림한다(순서를 보존하는 방향). 그 밖에서는 mpmath 적분과의 차이가 1.9×10⁻¹² 이하였다(무작위 1,500점). 상자 제거에는 여유 10⁻⁹를 둔다. 구간산술 인증은 아니며, 부동소수점 오차 모형 아래의 인증이다.

**의존성.** 명제 10은 명제 1(극값족 축소, 증명)에 기댄다. 정리 5, 5+와 명제 9는 명제 1과 무관하다.

**결과(E24, `results/certified_R.csv`).** q = .90, p ∈ {.90, .9036}, x = .010–.366 간격 5×10⁻⁴(점 713개씩).
- 인증 성공: p = .90은 712/713(x = .366만 실패), p = .9036은 706/713(x = .3585–.3615 실패).
- 인증 폭 (U − L)/L은 x ∈ [.05, .3]에서 모두 3×10⁻⁴이다. x < .05와 x ∈ [.3, .34]에서는 10⁻³–3×10⁻³, 가능성 경계(P(|e| ≤ 1) = p, x ≈ .37) 바로 앞에서는 1–10%다. L은 극값족 안의 가능한 분포가 주는 값이므로 참값 R은 [L, U] 안에 있다.
- 연속성 조회(명제 9, 조회 간격 5×10⁻⁴에서 벌점 ≤ .019·√(5×10⁻⁴) = 4.3×10⁻⁴)까지 포함한 인증 조회값은 x ∈ [.01, .34]에서 L의 최대 1.012배, 중앙 1.0014배다. x < .01에서는 정리 5(p = q) 또는 5+(p = .9036)의 닫힌 상한을 쓴다.
- 이전 표(E16 격자 최댓값, 계단 조회)와 비교했다. 격자에서 찾은 가능한 값 중 이전 표 값을 넘은 것은 없다. 인증 조회값은 이전 표보다 x ∈ [.02, .3]에서 최대 0.15%, x < .02에서 최대 0.35%, x ≥ .3에서 최대 1.2% 크다. 중앙값은 이전 표의 0.996배로 오히려 작다(조회 간격이 촘촘하기 때문).
- p = .9036 표는 p = .90 표보다 중앙 2.1% 작다(경계 근처에서는 최대 38%). PAC 절차는 순서통계량 사건 위에서 이미 noisy 질량 ≥ p_k를 갖으므로 이 표를 쓰는 것이 유효하다.

## 5B. 추정 분산 — 절차는 **증명**, 크기는 **수치**(2026-09-24 시작)

설정. D_i가 알려져 있지 않고, 잡음과 V에 독립인 추정량 D̂_i가 있다(정규 단위자료에서 표본평균과 표본분산은 독립). 순서통계량 사건 E_β(확률 ≥ 1 − δ, 명제 7)는 V만의 사건이다.

**보조정리 11(커널 지배, 증명).** D̂만으로 정해지는 사건 E_η(P ≥ 1 − η) 위에서, 모든 t > 0과 w에 대해 u_t(w) ≥ ḡ_{D,t}(w)인 함수 u_t가 있다고 하자. u_t가 연속이고 ±∞에서 0으로 가면, s = T·R_{p_k,q}[u_T]에 대해 Pr_{V,D̂}[Pr(|W_new| ≤ s | 자료) ≥ q] ≥ 1 − δ − η다.
증명. E_β ∩ E_η 위에서 ∫ u_T dG ≥ ∫ ḡ_{D,T} dG ≥ p_k이므로 G는 커널 u_T의 제약을 만족하고, R[u]의 정의(명제 1은 연속이며 무한에서 0인 커널 모두에 적용)로 Q_q(|W|) ≤ T·R[u_T]다. 합집합 상계로 P((E_β ∩ E_η)^c) ≤ δ + η이며 두 사건의 독립은 필요 없다. ∎
신뢰집합 𝒟_η(P(D ∈ 𝒟_η) ≥ 1 − η)가 있으면 s = T·sup_{d∈𝒟_η} R^mix_{p_k,q}(d/T²)도 같은 논법으로 1 − δ − η를 준다(E_η = {D ∈ 𝒟_η}).

**보조정리 12(척도 단조성, 증명).** 모든 분산을 같은 배수 λ ≥ 1로 늘리면 R^mix_{p,q}(λx) ≤ √λ·R^mix_{p,q}(x)다(혼합 커널 포함, 모든 p, q).
증명. W가 λx에서 가능하면 U = W/√λ는 avg_i P(|U + e_{x_i}| ≤ 1/√λ) ≥ p를 만족하고, 1/√λ ≤ 1이므로 임계값 1에서도 가능하다. 따라서 Q_q(|U|) ≤ R(x), Q_q(|W|) = √λ·Q_q(|U|). ∎ (동치: t ↦ t·R(D/t²)는 비감소.)

**구조적 분산 모형 S.** D_i = σ² a_i(a_i > 0 알려짐, 예: 1/n_i와 설계효과), σ² 공통. 합동 추정 σ̂²의 ν = Σ(n_i − 1)·σ̂²/σ² ~ χ²_ν이면 𝒟_η = {σ² a : σ² ∈ [ℓ, h]}, ℓ = νσ̂²/χ²_{ν,1−η₁}, h = νσ̂²/χ²_{ν,η₂}, η₁ + η₂ = η는 1차원이다. sup은 보조정리 12로 유한 개의 점으로 덮는다: σ² 격자 ℓ = s_0 < s_1 < … < s_m = h에서
  sup_{σ²∈[ℓ,h]} R^mix(σ² a/T²) ≤ max_j √(s_{j+1}/s_j)·U(s_j),  U(s) ≥ R^mix(s a/T²)(인증 상한).
R이 σ²에 대해 감소하는 구간에서는 s_{j+1}/s_j = (U(s_0)√r_0 / U(s_j))²로 칸을 넓혀 몇 개의 점만 쓴다. R이 단조라는 가정은 쓰지 않는다.

**지역별 신뢰구간 모형 H(모형 없는 비교 기준).** σ²_i가 지역마다 다르고 D̂_i = D_i χ²_{ν_i}/ν_i이면 곱 신뢰상자는 수준 1 − η/K가 필요해 ν_i = 1–2에서 쓸 수 없다. 대신 지역별 수준 1 − α 구간 [L_i, U_i]와 놓친 지역 수 N(Poisson-binomial, 각 확률 ≤ α → Bin(K, α)에 확률적으로 지배됨)의 상한 N*(수준 η)를 쓰면, E_η = {N ≤ N*} 위에서 모든 t, w에 대해
  ḡ_{D,t}(w) ≤ K⁻¹[Σ_i env_i(w) + (가장 큰 N*개의 M̃(w) − env_i(w))],  env_i(w) = sup_{x∈[L_i,U_i]/t²} g_x(w).
M(w) = sup_x g_x(w)는 |w| ≤ 1에서 1이고, |w| > 1에서 유일한 임계점 σ² = 2|w|/log((|w|+1)/(|w|−1))의 값(≤ 1/2)이다. |w| = 1에서 1 → 1/2로 뛰므로, 폭 .05의 경사를 더한 연속 상계 M̃를 쓴다. 그래야 u가 연속이고 ±∞에서 0으로 가서 보조정리 11의 조건을 만족한다(외부 검토 지적: 이전 구현은 상수 1을 써서 N* > 0이면 u → N*/K였다).
이는 보조정리 11의 u다. env_i는 A_x(w) = Φ((1 − w)/√x), B_x(w) = Φ((−1 − w)/√x)가 x에 단조라는 사실에서 max(A_L, A_U) − min(B_L, B_U) 이하로 닫힌 식을 갖는다.
